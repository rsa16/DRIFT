# AI usage

Agentic tools were used to assist with specific implementation tasks in building DRIFT. The project's scientific judgment, architectural decisions, and core logic were done by me. For example, the way the frames are compared, which frames were compared, and at what wavelengths, were all decisions I made.

Development tools were used only to assist with implementation, such as refactoring the FastAPI service, scaffolding the SvelteKit components and WebGL renderer, fixing  unhandled edge cases, No code was accepted without review. All assisted work was checked and run against static checks and unit and API tests. All documentation was written by me (however, AI was used to outline the sections I would be writing).
